# V22.9 Pixabay single-SFX mapping

## Important
The runtime sound architecture now uses exactly ONE file per sound event. Random variant pools were removed.

This environment can browse Pixabay and verify the license/pages, but it cannot retrieve the raw MP3 download bytes from Pixabay. The three collapsed events therefore retain a temporary single-file alias from V22.8 so the project remains buildable; replace the files below with downloaded/converted Pixabay assets before treating this as the final audio pass.
